IMAGINATION STUDIO v3.95 beta  (web version)

Upload everything in this folder to any static web host (GitHub Pages, Netlify, Cloudflare Pages, your own server).
No server code is needed. Do NOT add serve.ps1 to a public site.
Serve it over HTTPS and visitors can Install it as an app: it then works offline and updates itself - when you upload a newer build, users see an 'Update now' prompt the next time they open it.
The Claude tab works with the visitor's own Claude API key (stored in their browser only).
The app makes no other outside connections (the page's Content-Security-Policy enforces this).
